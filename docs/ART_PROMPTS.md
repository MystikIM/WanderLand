# WanderLand (InnerWorlds): copy-and-paste art prompts

228 ready prompts, one for every picture in [ART_INVENTORY.md](ART_INVENTORY.md). Each box is
**complete on its own**: copy the box, paste it into your image maker, save the result
under the name shown (in `assets/art/`), and tell me. On GitHub every box has a copy
button in its top corner.

**Tips**
- Pick the **same image maker and settings** for the whole set so it all matches.
- Do the **calm** picture first, then the **giggle** (or the other poses) with the calm
  picture attached as a reference: "same character, same style, but ...".
- Wrong size? Ask for square and resize it later. Needs transparency and the maker
  cannot do it? Ask for a plain white background and cut it out after.
- Image makers cannot spell. Anything with words: make it without words and add the
  text yourself.
- **Best order:** B (icon) first, then A (Inner World), then the Buddy species you use
  most, then D (frames).
